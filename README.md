# ⚡ Nova AI

> A futuristic Generative AI and agentic assistant interface designed for AI experimentation, prompt engineering, reasoning workflows, and interactive development.

## 🧠 Overview

**Nova AI** is a modern AI assistant interface built with React and Vite.

The project explores how a Generative AI workspace can combine conversational interaction, configurable AI parameters, prompt experimentation, code-oriented workflows, and interactive visual interfaces into a single application.

The interface is designed around the idea of an AI-powered development workspace rather than a traditional chatbot.

## ✨ Features

- 🤖 Generative AI assistant interface
- 🧠 AI model selection interface
- 🎛️ Adjustable temperature and maximum output controls
- 📝 Custom system instructions
- 💻 Interactive coding workspace
- 🧪 Prompt Lab for prompt experimentation
- 🕸️ Graph RAG Map interface
- 📊 Performance HUD with latency, token, and cost information
- 🎨 Customizable neural interface themes
- ⚡ Responsive modern UI
- 🚀 Deployed and accessible through Vercel

## 🚀 Getting Started
**Prerequisites**

Make sure you have:

- Node.js
- npm
- Git

## Installation

**Clone the repository:**

git clone https://github.com/A-Sandeep-Kumar/Nova-ai.git

**Navigate into the project:**

cd Nova-ai

**Install dependencies:**

npm install
Run Locally

**Start the development server:**

npm run dev

Open the local URL shown in the terminal.

## 🌐 Live Application

Nova AI is deployed and available online through Vercel.
